# Cinemas Star

Sistema de administracion y venta de boletos de peliculas.

# Descripcion

Aplicativo web que permite a los usuario comprar boletos de peliculas y comida online.

El sistema permite a los usuarios:

-Comsultal la cartelera.
-Ver funciones disponibles.
-Seleccionar boletos
-Comprar comida.
-Generar comprobante de compra.

Tambein cuenta con un panel administrativo para la gestion del cine.

# Funcionalidades

Gestion de peliculas:

-Añadir pelicula.
-Editar pelicula.
-Eliminar pelicula.

Gestion de funciones:

-Añadir funcion.
-Editar funcion.
-Eliminar funcion.

Gestion de productos:

-Añadir producto.
-Editar producto.
-Eliminar producto.

# Reportes:

-Peliculas mas vendidas.
-Recaudacion.
-Resumen de ventas.
